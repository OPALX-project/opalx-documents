## Changes

1. **Collective file creation.** `LossDataSink::save` now lets rank 0 choose create, append or metadata-inspection failure, then broadcasts that decision before any rank enters header or body output. Previously, one rank could observe a newly created file and skip the header while another entered its collectives. This explains the reported four-byte versus one-byte reduction mismatch. The change covers ASCII and HDF5 selection; it does not promise general recovery from every I/O failure.
2. **Reference-trial failure flushing.** The root-only trial publishes failure to every rank, then invokes collective flushing of already accepted probe hits before throwing. The existing two-argument `collectiveTerminalStep` symbol is retained. Successful trials publish a common duration, reference state and terminal flag, including for the bare single-particle path.
3. **Complete terminal RF kicks.** The reference owns `EKINSTOP`; physical particles finish the common accepted duration. A terminal-only endpoint allowance includes numerically unresolved upstream crossings. Ordinary crossings remain strict, and approaching, clearly upstream and radial-support guards remain in force. No position/time projection, extra drift or fractional impulse is introduced.

## Documentation and limits

Source Doxygen and the existing unified `opalx-manual` checkout document the common reference duration and terminal convention. Source validation, focused HTML rendering, formula/anchor/link checks and documentation catalog checks pass. `clang-format` 21.1.8 dry-run and whitespace checks pass. Independent source review approved the RF changes.

The terminal allowance is `delta = 64 * N * epsilon * L`, where `N` counts accepted frame steps including the current step and `L` is the laboratory coordinate scale with a one-metre minimum. It is a conservative arithmetic-resolution convention, not an ODE, magnetic/PIC discretization, nonlinear-trajectory or root-localization error bound. At 1,468 steps the allowance is about 39.5 pm, versus the observed 0.15 pm plane deficit.

A physically later arrival inside that allowance can receive the full terminal kick; offsets beyond it are excluded. Extremely small steps whose whole interval lies inside the allowance do not invent a crossing. Nonfinite or order-one accumulation factors are rejected. Parallel output still requires shared storage, and general coordinated recovery from every ASCII/HDF5 open/write failure remains outside this fix.
