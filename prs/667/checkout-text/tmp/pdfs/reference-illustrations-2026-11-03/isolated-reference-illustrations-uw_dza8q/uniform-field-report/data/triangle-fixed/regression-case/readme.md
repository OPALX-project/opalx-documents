# Frozen triangular-bunch longitudinal pipe regression

This is a native OPALX run, followed by an independent field validator. It
checks the nonzero `CIRCULAR_UNIFORM` longitudinal model, including its beam
interior, vacuum annulus and grounded-wall limit. It does not test tune shifts,
evolving-bunch tracking, transverse mesh accuracy or curved-source fields.

The fixed round beam has radius 5mm, full triangular length 10m and 1e14
400MeV protons. The physical pipe radius is 20mm and the open numerical box
has full width 60mm. One1e-20s step reads the fields while probe movement is
below3pm. The source consists of8192 longitudinal midpoint quantiles times
eight equal-area disk samples; sparse transverse sampling keeps the test
small because its longitudinal closure depends on the deposited line density
and prescribed beam radius. Separate tests check transverse fields.

Ten diagnostic particles lie at s=+/-2.5m, at r=0,a/2,a,(a+b)/2,b. The two
planes are far apart compared with the compact longitudinal gradient stencil.
Within a plane, symmetric CIC deposition and gather cancel its longitudinal
self contribution. BCHARGE includes the probes so the source charge remains
exactly1e14 elementary charges. No fitted coefficient enters the reference.

`validate.py --stat FFT2D5-TriangularPipe.stat` reads the companion HDF5 file,
reconstructs probe positions/fields, checks IDs, charge, units, time and frozen
motion, then integrates the uniform-disk Gauss-law radial field to the grounded
wall. Nonzero fields must agree within1%; wall fields use an absolute1e-4V/m
tolerance. The wall tolerance is about1e-8 of the characteristic on-axis field;
it uses an absolute bound because the reference value is zero. The standard
`.rt` RMS comparison complements this physical check.
Direct-launch runners must explicitly run the validator; `.rt` alone does not
check the longitudinal field. The validator requires Python, h5py and NumPy.

`prepare.py` regenerates the deterministic source, reference path, input and
fixture hashes using the Python standard library. Native outputs are never
used to construct the analytic field. Reference STAT files are generated by
the native run and serve only as conventional regression baselines.

FFT2D5 supports a single MPI rank. The local script launches it directly,
initializing MPI with a one-rank world; this also avoids machine-specific
MPI slot mapping. CI and the smoke harness may launch it explicitly with
one rank. Set `OPALX_EXE_PATH` to the binary directory and `OPALX_PYTHON` if
needed, then run `./FFT2D5-TriangularPipe.local`.
