# PR #667 historical FFT2D5 build records

Archived on 2026-11-10 from local build and checkout recovery records.
These are historical experimental sources, not the merged ORIGINAL solver or
code to apply directly to current OPALX. No archived code was executed.

- `sources/src/spacecharge/fft2d5/`: seven curvature, geometry and finite free-space implementation/header files.
- `sources/unit_tests/spacecharge/`: three corresponding tests.
- `sources/src/absbeamline/`: older FFA support header, superseded by current sources; retained to preserve the complete smaller source archive.
- `patches/`: two unique nonempty tracked-work patches. These include broader local edits and are historical evidence, not a ready-to-apply change.
- `provenance/`: unchanged build/checkout metadata, handoffs and helper scripts.
- `inventory.json`: per-file SHA-256, original paths, archive hashes and member modification dates. Duplicate origins share destinations.
- `task-state.json`: verification and cleanup outcome.

Paths and filenames here are lowercase; the inventory retains original names.
The larger `~/git/opalx-checkout-667-record/untracked-work.tar.gz` also holds
unrelated conversion-tool work and remains in place. Repository assets are
cataloged individually in `manifest.yml` with SHA-256 digests.
